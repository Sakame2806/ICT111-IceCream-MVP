# Acquisition Metrics

## Purpose
Define how the group will measure early user interest, landing page performance, and prototype engagement for IceCream.

## Required Metrics

| Metric ID | Metric Name | What It Measures | Formula / Counting Method | Data Source | Target / Success Criterion |
| --- | --- | --- | --- | --- | --- |
| M-01 | Landing page views | Number of people who opened the landing page from outreach channels | Count page views manually or via analytics mockup | Landing page / spreadsheet | Example: at least 30 views |
| M-02 | Sign-up button clicks | Number of users who clicked the "Join Beta" button | CTA clicks / page views | Landing page / manual count | Example: 20% click rate |
| M-03 | Prototype uploads | Number of users who tested the prototype by uploading artwork | Count artwork uploads | Prototype logs / localStorage | Example: 10 successful uploads |
| M-04 | Feedback responses | Number of users who submitted the structured critique or general feedback form | Count submitted feedback forms | Google Form / spreadsheet | Example: 10 responses |
| M-05 | Interest conversion | Percentage of visitors who joined the waitlist/beta | sign-ups / page views * 100 | Spreadsheet | Example: 15% conversion |

## Interpretation
What will the group do if the metrics are weak?

- Improve headline to better communicate the value of structured critiques.
- Change CTA text to be more inviting for artists.
- Simplify prototype flow for uploading artwork.
- Use a more relevant user channel if current outreach isn't reaching digital artists.
- Clarify benefit statement regarding how IceCream helps improve art skills.
