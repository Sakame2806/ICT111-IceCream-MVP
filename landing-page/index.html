How to use the prototype

Start the local server, then open the gallery.

IceCream stores and reads prototype data through its Python server. Complete these two steps before using the main page.

  1. 1

    Run the server

    Open a terminal in the project folder and run:

    python prototype/server.py Keep this terminal open while you use IceCream.
  2. 2

    Visit the main page

    After the server starts, open this address in your browser:

    http://127.0.0.1:8000/homepage.html → Use this server address instead of opening the HTML file directly.

The problem → the shift

01

Today

Good work vanishes too quickly.

In chat groups and general social feeds, artwork is quickly pushed away by new messages. Discovery depends on timing, and feedback often stops at emojis or short reactions.

Work stays organized and discoverable.

Artists publish to a dedicated gallery, add useful tags, present multi-image projects in order, and build a profile that keeps their work together.

Responsible by design

Share your work, not unnecessary personal data.

IceCream uses aliases instead of real names or student IDs. Passwords are stored as salted hashes in the local prototype. Uploaded files are used for educational demonstration and should contain only work you have the right to share.
